## Summary

Use RetroArch/libretro GLSL shaders and multipass presets in Godot games through
a pure GDScript post-processing layer.

## Description

Libretro Shaders for Godot loads `.glsl` shaders and `.glslp` presets at runtime.
It translates supported GLSL into Godot canvas shaders and presents the result
through a CanvasLayer, with no native extension or editor plugin activation.

Features include up to 16 passes, editable pragma parameters, lookup images,
per-pass sizing, original-frame and previous-frame inputs, feedback, mipmaps,
HDR and sRGB targets. Failed replacement presets preserve the active effect.
A bounded translation cache speeds up repeated loads.

Copy `addons/retroarch_shaders` into your project and run `demo/demo.tscn` for a
complete integration example. The included demonstration uses synthetic artwork
and an original scanline shader, so it runs without an external collection.
For game integration, render your source through a SubViewport and supply its
texture to the post-process node. Integration and API documentation are included.

Tested with Godot 4.7.1 on Windows using the Compatibility renderer. Slang and
Cg shaders are outside this release's scope. Loading and translation run on the
main thread; advanced temporal pipelines add one frame of presentation delay.
Collection compatibility is documented per source snapshot and does not imply
pixel equivalence with RetroArch.

External shaders, presets and lookup images are supplied separately and retain
their own licenses. The MIT license covers this add-on and its original demo.

## Version notes

First stable release of the GDScript GLSL importer and post-processing API.
Includes an independent demo, documentation, shader regressions, deterministic
packaging and fresh-project installation checks. Import type lowering avoids
repeated parsing and searches. Output resizing preserves unchanged history and
feedback textures, reducing allocations and retaining temporal pixels.
